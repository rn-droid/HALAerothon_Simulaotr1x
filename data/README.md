# Data Directory

This directory stores all input data, simulation outputs, and intermediate results.

## Sub-directories

| Folder | Purpose |
|--------|---------|
| `inputs/` | Static input files: BSFC tables, propeller maps, material data |
| `outputs/` | Simulation result CSVs and DataFrames (auto-generated) |
| `cache/` | Cached optimization runs and intermediate sizing iterations |
